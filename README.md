# DnD-DM-Panel-free-
Darmowy panel D&amp;D do postawienia u siebie na komputerze, tworzenia kampanii i jej prowadzenia za darmo (wersja do przetestowania)
A free D&D dashboard you can host on your own computer to create and run campaigns at no cost (evaluation version)
This Panel isproject to make an FREE web / local alternative of DM + players campain app that has an useful elements as map, chat, dice, local serwer (VPN too), install app, character creation with leveling them as DND 5E was intended.
